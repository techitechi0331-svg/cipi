# MIDNIGHT HIGHWAY — Ver.0.5.9 handbrake-release / drift recovery patch
Date: 2026-11-02
Review state: **Browser automation passed; Windows runtime and human steering/drifting unverified**.
CIPI role: public handoff and measured change log only. Private game files **not committed**.

## User-reported defect
During touge drifting, lifting the **Space** handbrake key caused an instantaneous “gyun” / severe snap-back. User found it difficult to control. Reference build: Ver.0.5.8.

## Root cause (source inspection + deterministic reproduction)
In Ver.0.5.8, `sliding=drift||hb` switched from true to false instantly on handbrake release in GRIP style. Lateral velocity was then forced toward zero with gain 8/s **and** multiplied by `exp(-7.2*dt)` every 1/120s frame. This caused unrealistically sharp lateral momentum loss (~0.05s half-life), abruptly changing the projected body trajectory. It was not a steering input or human error.

## Fixes in Ver.0.5.9
- FIX-059-01: Introduced continuous rear-slide state `state.handSlip`, applied in fixed 120Hz physics integration. Handbrake builds slip in ~0.13 seconds and restores rear grip after key release in ~0.65 seconds. This state is based **only on driver input**.
- FIX-059-02: Replaced hard `sliding` switch, fast lateral velocity damping, and instantaneous front-grip/yaw-response changes with smooth blends. Post-release lateral velocity relaxes progressively, preserving countersteer control.
- FIX-059-03: Rotation and lateral **kick torque** apply only while handbrake is physically held; the body's residual yaw and lateral momentum persist naturally after release. No new autonomous braking, lane-centering, or road-tracking steering.
- FIX-059-04: HUD shows `REAR GRIP RETURNING XX%` during recovery.
- Maintains both GRIP and DRIFT modes, lane/traffic controls, keyboard mapping and manual recover.

## Deterministic release comparison
Linux Chromium/SwiftShader; `touge`, `KAZE S86`, 68 km/h, tire tier 2, steering LIGHT, traffic OFF; 35 physics steps D, 36 steps D+Space, followed by Space release and D/countersteer. Measurements from one 1/120s step after release:

| metric | Ver.0.5.8 | Ver.0.5.9 |
| --- | ---: | ---: |
| Absolute lateral velocity change in first 8.33ms (GRIP) | **0.9247 m/s** | **0.1216 m/s** |
| Absolute lateral velocity change over first 10 steps (GRIP) | 5.5375 m/s | 0.9318 m/s |
| Lateral velocity at end of subsequent countersteer/neutral sequence | ≈0 m/s | -0.273 m/s |
| Slip angle at end of sequence | ≈0° | 1.60° |

The post-release response is demonstrably more gradual, **not yet human-certified or physically calibrated to a real car**. Touge test encountered a wall contact under this specific scripted steering sequence; do not infer that all touge corners are solved. Both original and patched test traces are available as transient local file `MIDNIGHT_HIGHWAY_V0.5.9_DRIFT_TEST.json`, NOT persisted in this public CIPI repository.
