## User / audible goal

The requested target is not “more top end” or “more compression” by itself.

Primary audible target:

- low end remains full but not muddy or boxy;
- upper mids/highs remain open and bright but do not stab the ear;
- sibilance remains intelligible but not painful;
- density and level stability improve without obvious pumping or flattening;
- the default 50% position should be a useful nominal professional starting point, not merely a weak/safe midpoint;
- users should be able to operate the plug-in mainly by ear rather than chasing meters.

Product role:

> A dry-vocal “surface / comfort / mix-readiness” processor. It is not intended to replace pitch editing, timing editing, noise repair, reverb/delay throws, or detailed song-level vocal automation.

## Version history carried forward

### v0.1

Initial working prototype.

Key problem discovered:
- local macro values and Amount were multiplied directly, so 50% x 50% often produced only 25% effective depth;
- the spectral path also incurred additional wet scaling;
- subjective result: the nominal 50% position was too conservative to represent the intended standard starting point.

### v0.2

50% calibration redesign.

Core change:
- UI 50% maps to internal nominal strength 1.0 rather than literal 0.5;
- lower half preserves subtle-control resolution;
- upper half adds bounded headroom rather than allowing runaway depth.

Macro mapping at equal Amount/local values:

| UI | Amount map | Local map | Combined strength |
|---:|---:|---:|---:|
| 0% | 0.000 | 0.000 | 0.000 |
| 25% | 0.4375 | 0.4500 | 0.196875 |
| 50% | 1.000 | 1.000 | 1.000 |
| 75% | 1.240625 | 1.196875 | 1.484873 |
| 100% | 1.550 | 1.450 | capped at 1.800 |

v0.2 also established the nominal few-dB-per-stage philosophy rather than one aggressive processor doing all work.

### v0.3 — current repository version

Repository reports `project(... VERSION 0.3.0)`.

Repository README states that v0.3:
- keeps the validated v0.2 detector architecture;
- removes the low-Amount spectral dry/wet double-scaling failure mode;
- makes Air smoothing time-based instead of DAW-buffer-size dependent;
- keeps the STFT analysis window near 21–23 ms through high sample rates;
- adds stronger validation coverage;
- latest main also adds a persistent VST3 Bypass parameter and a named Default factory program.

## Current user-visible controls

Current APVTS/default state:

- Amount = 50%
- Clean = 50%
- Smooth = 50%
- Density = 50%
- Air = 50%
- Output = 0.0 dB
- Auto Gain = ON
- Bypass = OFF

Meaning:

- **Amount** — global processing intensity. 50% is the nominal operating point.
- **Clean** — dynamic low / low-mid cleanup.
- **Smooth** — spectral harshness + sibilance control.
- **Density** — serial fast-peak + slower leveler depth.
- **Air** — adaptive high-shelf restoration.
- **Output** — final trim, -12 to +12 dB.
- **Auto Gain** — slow bounded level compensation.
- **Bypass** — host-persistent bypass parameter; preserves the plug-in's identity path.

The intended quick-start instruction for users is:

> Start with Amount / Clean / Smooth / Density / Air at 50%, Auto Gain ON, Output around 0 dB. Adjust by ear from there.

## Current signal flow

```text
INPUT
  -> Dynamic Low-Mid Cleanup
  -> Shared STFT Harshness / Sibilance Control
  -> Fast Peak Controller
  -> Slow Program-Dependent Leveler
  -> Sibilance-Aware Air Restore
  -> Slow Bounded Auto Gain
  -> Output Trim
OUTPUT
```

This order is the current implementation, not an immutable truth. It may be changed if real-vocal evidence demonstrates a better ordering.

## Current DSP — repository-verified facts

### 1. Clean / low-mid section

Three linked dynamic bands:

| Band | Center | Detector Q | Audio Q |
|---|---:|---:|---:|
| Low body | 180 Hz | 0.85 | 0.80 |
| Mud | 310 Hz | 1.00 | 0.95 |
| Box/cloud | 520 Hz | 1.10 | 1.05 |

Detector envelope:
- attack 18 ms;
- release 220 ms.

At nominal internal strength = 1.0:
- 180 Hz max reduction = 1.8 dB, threshold -29 dB;
- 310 Hz max reduction = 2.4 dB, threshold -31 dB;
- 520 Hz max reduction = 1.6 dB, threshold -33 dB.

Dynamic-band reduction time constants:
- 180 Hz: attack 34 ms / release 300 ms;
- 310 Hz: attack 28 ms / release 330 ms;
- 520 Hz: attack 22 ms / release 270 ms.

The low section is intentionally IIR / broad-band dynamic cleanup rather than full spectral flattening of fundamentals.

### 2. Spectral Smooth section

Current architecture:
- shared STFT engine for harshness + sibilance;
- square-root Hann analysis/synthesis window;
- hop size = FFT size / 4;
- FFT order:
  - <= 60 kHz sample rate: order 10 / 1024 samples;
  - > 60 kHz to 150 kHz: order 11 / 2048 samples;
  - > 150 kHz: order 12 / 4096 samples.

Primary weighting regions:
- harshness weighting: 1.7–9.0 kHz with 700 Hz transition;
- sibilance weighting: 4.8–11.5 kHz with 1 kHz transition.

Current relative-prominence model:
- compares current spectrum against local smoothed spectrum and slow baseline;
- reference = max(local, slow baseline - 1.5 dB);
- prominence = current - reference.

At nominal spectral strength 1.0:
- harshness prominence threshold = 5.8 dB;
- harshness slope = 0.55 x excess prominence;
- nominal harshness cap before weighting = 3.2 dB;
- sibilance term nominal depth = up to 2.4 dB weighted by activity/band;
- total spectral cap at nominal = 4.5 dB.

Above nominal:
- threshold can move toward 3.8 dB;
- depth scale rises toward 1.45;
- total cap rises toward 6.2 dB.

Important v0.3 behavior:
- depth is applied internally via nominalDepth rather than being attenuated again by a second output wet/dry scaling at low Amount.

### 3. Fast Peak Controller

Sidechain HPF:
- 85 Hz.

Detector:
- hybrid Peak/RMS;
- peak envelope 0.20 ms attack / 35 ms release;
- RMS envelope 20 ms / 100 ms;
- crest-factor-dependent peak weighting clamped 0.25–0.80.

Adaptive activity reference:
- attack approximately 1.2 s;
- release approximately 5 s.

At nominal Density strength 1.0:
- threshold offset = 4.0 dB below active reference;
- attack = 3.0 ms;
- release = 95 ms;
- ratio = 1.60:1;
- soft knee = 6 dB;
- max GR = 2.2 dB.

Strong-end limits:
- threshold offset up to 6.2 dB;
- attack toward 1.7 ms;
- release toward 70 ms;
- ratio toward 2.20:1;
- max GR toward 3.6 dB.

### 4. Slow Program-Dependent Leveler

Sidechain HPF:
- 70 Hz.

Adaptive activity reference:
- attack approximately 1.8 s;
- release approximately 7 s.

At nominal Density strength 1.0:
- threshold offset = 2.8 dB;
- ratio = 1.35:1;
- knee = 8 dB;
- attack = 22 ms;
- max GR = 2.8 dB;
- release is program-dependent, nominally from about 420 ms toward 1100 ms as sustained reduction increases.

Strong-end:
- threshold offset toward 4.6 dB;
- ratio toward 1.65:1;
- max GR toward 4.2 dB;
- long release can reach about 1300 ms.

### 5. Adaptive Air

Filter:
- high shelf at 11.5 kHz;
- Q/slope parameter 0.707.

At nominal Air strength:
- requested boost = +1.5 dB.

Strong-end:
- requested boost can rise toward +3.2 dB.

Sibilance safety:
- derives from spectral sibilance reduction / 3 dB;
- safe Air = requested Air x (1 - 0.55 x sibilanceSafety).

v0.3 Air smoothing:
- time based, approximately 64 ms;
- deliberately independent of host buffer size.

### 6. Auto Gain

Purpose:
- reduce loudness-bias during processed/bypass comparison, not drive the compressor detector.

Current behavior:
- compares block input/output RMS;
- bounded to +/-3 dB;
- does not update for very quiet input/output;
- slow response;
- disabled when Amount is effectively zero or host Bypass is active.

### 7. Output / realtime

- Output range: -12 to +12 dB.
- Output gain smoothing: 50 ms.
- No intentional saturation / clipping stage.
- No oversampling in the core because the current main signal path is not intentionally nonlinear.
- NaN/non-finite output is guarded to zero.
- denormal protection is used in the AudioProcessor.

## Why several candidate ideas were rejected or deferred

### Saturation in the core
Rejected/deferred because it is not required to achieve the current “comfort / mix-ready” objective and can reintroduce:
- sibilance;
- high-frequency fizz;
- IMD;
- aliasing;
- unwanted coloration.

If added later, it must be isolated, tested, and oversampled only where justified.

### Full-spectrum FFT treatment of the low end
Rejected because it risks over-following fundamentals/formants and thinning the voice. Low-mid cleanup remains broad dynamic IIR.

### One detector for Harshness + Sibilance
Rejected. They are related but not identical phenomena and require separate weighting/activity logic.

### Fixed Air boost
Rejected. Air is intentionally reduced when sibilance activity is high.

### “More complicated = better”
Explicitly rejected. Every future stage must justify problem solved, side effects, CPU, latency, and why an existing stage cannot solve it.

## 50% design meaning

50% is not claimed to be a universal optimum for every singer, microphone, genre, or recording.

It means:

> The nominal center point chosen to give a well-recorded modern vocal meaningful but bounded low cleanup, spectral comfort, serial dynamics, and air restoration without requiring the user to turn every control far above the midpoint.

The intended UX semantics are:

- 0% = effectively off / no processing for that macro;
- 25% = very light correction;
- 50% = nominal professional starting point;
- 75% = clearly stronger correction;
- 100% = strong correction but still capped for safety.

## Main unresolved technical risk

The largest DSP-quality risk is still **spectral false positives**:

- legitimate formants;
- singer's-formant/ring concentrations;
- high-register harmonic clusters;
- intentional bright vowels;

can look like “spectral prominence” and be incorrectly attenuated.

CIPI already has relevant shared sources:
- VOX-001 / VOX-002 / VOX-003;
- RES-001;
- RES-PROD-001..004;
- DATA-VOX-001 / DATA-VOX-002.

Do not freeze the spectral detector until harmonic/formant protection is tested on real singing.

## Product-use guide preserved for regeneration

One-page quick-guide copy:

### What it does
- clean low/low-mid mud;
- smooth harsh highs and sibilance;
- stabilize density/frontness;
- add open Air without stabbing;
- gently compensate level.

### Flow
Input -> Clean -> Smooth -> Density (Peak -> Leveler) -> Air -> Auto Gain -> Output

### Quick start
- Amount 50%
- Clean 50%
- Smooth 50%
- Density 50%
- Air 50%
- Output around 0 dB
- Auto Gain ON

### Troubleshooting
- muddy -> raise Clean slightly;
- highs stab -> raise Smooth and/or lower Air slightly;
- still dull -> raise Air slightly;
- vocal does not sit forward -> raise Density slightly;
- crushed/unnatural -> lower Amount or Density;
- level too high -> lower Output.

### Main usage philosophy
- judge mainly by ear;
- match bypass loudness;
- listen in the full mix, not only solo;
- if overdone, reduce Amount first;
- meters are optional diagnostics, not the main target.
