# Plugin Incubator artifacts

The Incubator stores product proposals, non-final automation decisions and isolated experimental prototypes.

Automation decisions are advisory only:
- `REJECT`
- `ITERATE`
- `MERGE_EXISTING`
- `INCUBATE`
- `ARCHIVE`

`MERGE_EXISTING` means the research mechanism should be reviewed in an existing product track instead of spawning another plug-in.

Only a reviewed `INCUBATE` proposal may invoke an allowlisted prototype adapter. Experimental prototypes are not production VST3 releases.
