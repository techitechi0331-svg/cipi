# Incubator Factory Contract Candidates

Contract candidates are generated only by the gated Incubator-to-Factory handoff.

Each candidate directory contains:

- `plugin_contract_candidate.json`
- `handoff_receipt.json`

The receipt pins SHA-256 hashes for the proposal, INCUBATE decision, product
evidence and Manufacturing Review, plus the semantic Plugin Contract hash.

`CONTRACT_CANDIDATE` is not Factory build approval. Build authorization, VST3
validation, Cubase confirmation, listening review and release remain separate gates.
