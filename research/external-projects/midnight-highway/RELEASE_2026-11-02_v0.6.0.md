## Actual implemented changes
1. **Engine torque and transmission**: replaced velocity-band synthetic gear/RPM with six real ratio values (3.35, 2.13, 1.52, 1.17, .94, .74) and final drive. RPM is derived from wheel speed and gear; torque varies with RPM, engine tune and ratio. AT up/down-shifts by RPM; MT Q/E changes gear, M switches AT/MT. Shift introduces ~0.22s torque interruption. Engine sound and gauge now follow computed RPM. This is still a **simplified engine/clutch model**.
2. **World-space car state**: independent `worldX/worldZ` coordinates are integrated from heading, forward and lateral velocity; projection onto the course is only used for longitudinal route progress/offset and barrier checks. Barrier contact clamps position; it does not activate automatic corner steering or braking. This is a groundwork step, **not** a four-wheel or full dynamic tire model.
3. **Rival decisions**: route-following AI evaluates traffic clearance and changes to an open lane with gradual lateral motion; adjusts target speed for curvature and obstructing cars. Race ends when either contestant finishes, with separate winning/losing result. Rival contact causes relative-speed-dependent damage. Opponent is still a lane/route-level AI, not a fully physical car.
4. **Highway following / drafting**: a close car in the same lane can decrease the player's aerodynamic drag by up to 19%, without introducing automatic acceleration, steering or slowing. HUD indicates SLIPSTREAM.
5. **Career persistence**: local rival win count and completed runs stored under `mh06-career`; existing `mh05-settings` and `mh05-bests` keys remain for save compatibility.
6. **UI/controls**: added transmission selector, GEAR AT/MT toggle, real engine RPM readout and manual shift keys Q/E. Existing A-left/D-right, Space handbrake, Shift precision steering, C recovery, T traffic and G GRIP/DRIFT remain.

## Reproducible verification
- Test environment: Linux Chromium using SwiftShader GPU WebGL and separately forced Canvas2D fallback; simulated 1/120s physics updates.
- **26/26 automated regression checks** passed across the two renderers. Each renderer independently passed **36/36** combinations (2 courses × 3 race modes × 3 cars × 2 driving styles); total **72 combination smoke cases**.
- Verified: A-left and D-right in both courses, actual RPM/gears after AT changes, MT manual gear switch, finite world positions, handbrake-release transition, rival lane move away from intentionally blocked lane, START button with no JS exceptions.
- Additional physical keyboard input via Chromium: `E` upshifted 3→4, after shift cooldown `Q` downshifted 4→3, `M` changed MT→AT. No page error.
- Archive `zipfile.testzip()`, payload manifest SHA-256 matches, x64 PE `MZ` header and embedded HTML signature checked. **No Windows 10/11 execution or UPDATE_GAME.ps1 rollback test**.
- A 15-second unattended acceleration script without steering contacted the highway walls 8 times and slowed; this is not considered a handling pass because roads curve and the game intentionally has **no hidden automatic corner steering**.
- Player's 4-wheel dynamics, human keyboard drifting fun factor and high-speed race balance remain **NOT VALIDATED**.
