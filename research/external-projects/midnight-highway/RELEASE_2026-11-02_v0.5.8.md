## Repairs
- FIX-058-01: ShiftLeft / ShiftRight were absent from the accepted key codes, making the advertised precision-steering shortcut inert. Both keys now accepted and validated using an actual keyboard event.
- FIX-058-02: Persisted invalid or stale settings could break rendering/startup or vehicleStats. Validate allowed course, game mode, vehicle, setup, colors, gear ratio, traffic, time of day and steering mode; clamp engine/tires/suspension values; sanitize best times.
- FIX-058-03: Handle WebGL context loss during gameplay by switching to Canvas2D fallback, with a visible notification; preserve the session state.
- FIX-058-04: Previously the Canvas2D renderer discarded an entire triangle if any corner crossed the camera near plane. Implemented near-plane polygon clipping. The painter-sort fallback is still not perfect depth rendering.
- FIX-058-05: Windows manual updater now keeps a timestamped backup, uses File.Replace on the same volume, and attempts automatic restore on update failures. **Not verified in Windows PowerShell**.

## Open risks and human gate
- Repeated user feedback through v0.5.6: touge was not pleasant / sufficiently turnable. **v0.5.8 test automation is not equivalent to human approval**. Human steering and drift playtesting remain mandatory.
- Windows 10/11 launcher startup and PowerShell update/rollback tests not yet run.
- Browser Canvas2D fallback uses approximate painter ordering; complex occlusion can differ from WebGL.
- Update origin authentication and signatures remain unavailable. Do not claim update is securely auto-delivered.
- Future development should keep game source in a **separate private repository**, not assume Unity HighwayPrototype is this HTML game's codebase.
