# Research Architect artifacts

This directory stores append-only Research Gap and Research Proposal artifacts generated by the bounded Research Architect.

A gap is a statement that current CIPI evidence is insufficient for a reviewed topic. A proposal converts that gap into a falsifiable research contract.

States:
- `PILOT_READY`: an allowlisted safe pilot exists;
- `NEEDS_ADAPTER`: the research question is valid but execution support must be reviewed/implemented separately;
- `RESEARCH_MORE`: more evidence is needed before formalization;
- `ARCHIVED`: retained but not active.

These artifacts never authorize product release or knowledge CONFIRMED status.


## Adapter Candidates

`research/architect/adapter_candidates/` contains non-executable implementation contracts derived from `NEEDS_ADAPTER` proposals.

They make unknown research themes actionable without granting the scheduled runner arbitrary code-generation or Adapter Registry authority. A candidate stays review-only until a separate implementation is written, tested and explicitly approved.
