## 1. Product target and non-negotiable user requirements

- Original Japanese street racing game: **Assetto Corsa-like driver-controlled vehicle behavior** + **Wangan Midnight-like highway speed battles** + **Initial D-like touge/hairpin drifting**. These are reference goals, **not** a claim of parity or license to copy protected assets.
- Third-person chase camera behind the car; appealing sense of real speed.
- Selectable **wide 4-lane expressway** and **2-lane mountain pass** with hairpins, elevation and real drifting; future scenery, tunnels and junctions.
- Garage / tuning that affects actual driving: car, engine, tires, suspension, gear ratio, color.
- Traffic cars toggleable (including off), free run / time attack / rival race, night/sunset.
- **FULL MANUAL: no automatic corner braking, lane-centering or automatic steering**. No hidden assist reintroduced to hide physics bugs.
- Keyboard controls must be correct: **A/← = LEFT**, **D/→ = RIGHT**; steering should be responsive but controllable. Drifting must be possible using handbrake + countersteer.
- Deliver an independent Windows **.exe launcher** and easy incremental updates; user prefers standalone downloadable builds rather than an in-chat embedded game.
- Preserve playable previous builds; do not describe a bug as fixed without reproduction and regression testing.

## 4. Current technical limitations / risks

1. The current physics is a simplified vehicle model: NOT Assetto Corsa's full tire/contact/suspension solver; keyboard-friendly drift behavior requires repeatable tests and user playtest.
2. Authentic touge hairpins can exceed grip limits if approached too fast, but legitimate slip must not be confused with broken steering or camera axes. Validate geometry and vehicle physics together.
3. Prior visual problems: inverted left/right camera, depth transparency/fallback ordering, shader uniform precision mismatch. Add renderer QA, maintain feature parity where possible.
4. User reported artificial ~65km/h corner speed cap; **never reintroduce automatic corner braking**. Resist substituting hidden steering assists for proper physics fixes.
5. Windows `.exe` is unsigned and uses installed Edge; Windows machine execution and update/rollback are not yet proven.
6. The build files above are local conversation artifacts only. A **dedicated private game source repository + tagged releases** has not been established for this precise HTML game. Do not silently treat the separate `HighwayPrototype` Unity repo as this game.
7. Public CIPI must store only non-sensitive specifications, hashed build identifiers and evidence/decisions. Do not commit private code, tokens or binaries or run external CIPI automations without review.
